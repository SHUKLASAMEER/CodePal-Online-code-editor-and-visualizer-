# CodePal - Online Code Editor and Visualizer

A fully responsive, interactive online code editor with real-time DSA (Data Structures & Algorithms) visualization. Master complex data structures and algorithms through interactive animations, live code analysis, and hands-on practice challenges.

## 🚀 Quick Start

### Frontend Only (No Backend Required)
```bash
cd /workspaces/CodePal-Online-code-editor-and-visualizer-
python -m http.server 8000
# Visit: http://localhost:8000
```

### Full Setup (With Backend)
```bash
npm install
npm start
# Backend: http://localhost:3000
```
